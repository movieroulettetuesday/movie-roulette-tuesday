What's New in Each Beta Build

Every TestFlight build of Movie Roulette Tuesday, newest first. Thanks to everyone who sent feedback!

Build 8 (Oct 14, 2026)

  • Movie pages always show Where to Watch. When there's no data, they say "No streaming sources found."

Build 7 (Oct 14, 2026)

  • Episode About sections show the full show notes instead of cutting off long descriptions. (Thanks, Karl!)
  • The Host Rating section is hidden for now.

Build 6 (Oct 14, 2026)

  • The About screen in Settings now correctly calls this the official companion app from the hosts of Movie Roulette Tuesday: The Podcast.

Build 5 (Oct 14, 2026)

Fixes

  • The episode totals on the Episodes and Movies tabs now match.
  • The category under a movie's title now matches the Categories list.
  • Episode descriptions no longer start with the "Send us Fan Mail" text.
  • Times Spun no longer shows 0 on the Movie Page after a spin.

New

  • Tap the wheel to stop a spin early.
  • Half-star ratings.
  • Send suggestions by email, or with the in-app form if you don't use Apple Mail.
  • Episodes are grouped by season.
  • You can select and copy text.
  • Where to Watch shows streaming info. Pick your services in Settings, then filter or sort the Movies tab by them.
  • Polls and ratings are now live.

Build 4

  • The movie catalog now updates online, so new episodes show up without an app update.

Build 3

  • Added the privacy details Apple requires.

Build 2

  • After a spin, the movie page's episode link now opens that episode. (Thanks, Karl!)
  • The Spotify "Listen" button opens the podcast directly instead of a search. (Thanks, Rachael!)

Build 1

  • First beta.
